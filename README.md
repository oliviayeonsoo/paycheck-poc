# 페이체크 PoC

외국인 직원 급여 이체에 붙는 **은행 앱 탑재 서비스** "페이체크"의 PoC예요.
"사장님을 위한 금융 아이디어 공모전" 제출용 데모이고, **실제 금융 서비스가 아니에요.**

휴대폰 브라우저로 열면 앱처럼 화면 전체를 쓰고, 데스크톱에서는 폰 프레임과 장면 목록이 함께 보여요.

## 무엇을 눌러 볼 수 있나

사장님 5단계와 직원 화면 2장을 실제로 이어서 눌러 볼 수 있어요.

| 단계 | 화면 | 동작하는 것 |
|---|---|---|
| 연결 | 사장님 홈, 직원 등록 | 공제 템플릿, 사장이지 연동 토글 |
| 준비 | 급여일 미리보기 (D-3) | 잔액 부족 계산, 운전자금으로 채우기 |
| 점검 | 이체 확인 | 최저임금(2026년 10,320원)과 숙식비 서면 동의 금액 점검, 공제 수정 후 재점검, 4대보험료 고지액 확인과 납부 방식 선택(납부기한 자동 납부 또는 지금 함께 내기) |
| 지급 | 이체 완료 | 이체 시각으로 지급 확인 명세서 발송, 4대보험료 납부 또는 예약 |
| 증명과 보상 | 급여 기록 | 열람과 대조 현황, 직원 문의 번역, 답장, 기록 PDF(인쇄) |
| 직원 | 카카오톡 알림, 모국어 명세서, 사장님 카톡방 | 베트남어, 네팔어, 포르투갈어, 한국어 전환, 공제 항목 설명, 문의하기(질문을 고르면 사장님 카톡방 입력창에 사장님께 보낼 한국어 메시지와 명세서 첨부, 그 위에 직원 언어로 뜻풀이) |

데모 시나리오: 응우옌 반 A의 숙식비가 이번 달에 350,000원으로 잘못 들어가 있어요. 이체 확인 화면에서 서면 동의 금액(300,000원)보다 많다는 알림이 뜨고, "지난달과 같게"로 고치면 총액 9,520,000원, A의 실수령 2,380,000원으로 발표 자료와 같아져요.

- 데스크톱 오른쪽 안내판이나 휴대폰 왼쪽 가장자리 손잡이에서 장면을 바로 열고, 탑재 은행과 직원 화면을 바꾸고, 처음부터 다시 시작할 수 있어요.
- 진행 상태는 브라우저 저장소(localStorage)에만 남아요. 서버로 보내는 데이터는 없어요.

### 화면별 페이지

같은 앱을 세 가지 페이지로 열 수 있어요. 진행 상태는 페이지마다 따로 저장돼요.

| 페이지 | 주소 | 쓰임 |
|---|---|---|
| 전체 데모 | `https://oliviayeonsoo.github.io/paycheck-poc/` | 발표용. 사장님과 직원 화면 전체, 데모 메뉴 |
| 사장님 화면 | `https://oliviayeonsoo.github.io/paycheck-poc/owner/` | 사장님 인터뷰용. 홈부터 급여 기록까지, 데모 메뉴와 직원 화면 바로가기 없음 |
| 직원 화면 | `https://oliviayeonsoo.github.io/paycheck-poc/worker/` | 직원 인터뷰용. 언어 고르기, 카카오톡 알림, 모국어 명세서, 사장님 카톡방만. 급여가 나간 9월 25일 상태에서 시작하고, 메시지는 보내기 직전에서 멈춰요 |

- 직원 화면을 특정 언어로 바로 열려면 `worker/?lang=pt`(포르투갈어), `?lang=vi`(베트남어), `?lang=ne`(네팔어)를 붙여요. 예전 주소(`/paycheck-poc/?lang=pt`)도 직원 화면으로 넘어가요.
- 주소 끝에 `?reset`을 붙여 열면 그 페이지를 처음 상태로 되돌려요. 같은 휴대폰으로 인터뷰를 이어서 할 때 써요. 예: `owner/?reset`

## 파일 구성

빌드 도구 없이 정적 파일만으로 돌아가요.

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 틀 (사장님 데모) |
| `owner/index.html` | 사장님 전용 페이지. 같은 앱을 `data-mode="owner"`로 열어요 |
| `worker/index.html` | 직원 전용 페이지. 같은 앱을 `data-mode="worker"`로 열어요 |
| `styles.css` | 디자인 토큰과 컴포넌트 (네이비 `#0B1F4F`, 노랑 `#FFE300`, Pretendard) |
| `app.js` | 화면, 해시 라우팅, 시트, 상태 저장 |
| `engine.js` | 명세서 계산과 이체 전 점검 |
| `data.js` | 직원, 금액, 번역 문구 (모두 예시) |
| `.github/workflows/pages.yml` | `main`에 푸시하면 GitHub Pages로 배포 |

## 로컬에서 보기

```bash
python3 -m http.server 8000
# http://localhost:8000 을 휴대폰 크기 브라우저로 열기
```

## 배포

- 파일을 고친 뒤에는 `index.html`, `owner/index.html`, `worker/index.html`, `app.js`, `engine.js`에 붙은 `?v=` 값을 함께 올려 주세요. GitHub Pages는 파일을 10분 동안 캐시해서, 값을 올리지 않으면 휴대폰에 예전 화면이 남을 수 있어요.

1. 저장소 **Settings > Pages > Build and deployment > Source**를 **GitHub Actions**로 한 번 바꿔요.
2. `main`에 푸시하면 Actions가 자동으로 배포해요. 주소는 `https://<계정>.github.io/<저장소>/`예요.

## 주의

- 이름, 금액, 대출 조건, 혜택, 은행 화면은 모두 예시예요.
- 베트남어, 네팔어, 포르투갈어(브라질) 문구는 PoC용 번역이라 **원어민 검수가 필요해요.**
- 명세서의 법적 효력은 한국어 원문 기준이라는 전제로 한국어를 함께 표시해요.
